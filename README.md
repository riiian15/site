# МедУЗИ — продажа, аренда и сервис УЗИ-оборудования

## Быстрый запуск (без PHP — демо-режим)

Фронтенд работает полностью автономно: если PHP-бэкенд недоступен,
`js/api.js` автоматически включает **демо-режим** с локальными данными
(категории, товары, оформление заявок).

```bash
cd frontend
python3 -m http.server 8099
# откройте http://localhost:8099/index.html
```

Можно и просто открыть `frontend/index.html` двойным кликом (file://) — тоже работает.

## Полный стек (PHP + MySQL)

1. Настройте БД: скопируйте `backend/config/database.example.php` → `database.php`, укажите доступы.
2. Импортируйте схему (если есть SQL-файлы в `backend/`).
3. Разместите проект на любом PHP-хостинге (или `php -S localhost:8080` из корня репозитория).
   Фронтенд сам найдёт API по путям `/site/backend/api`, `../backend/api`, `/backend/api`.

## Структура

```
frontend/          статический фронтенд (HTML/CSS/JS, без сборки)
  index.html       главная
  catalog.html     каталог (фильтры, поиск, сортировка)
  product.html     карточка товара
  rental.html      аренда
  cart.html        корзина/заявка
  request.html     форма заявки
  css/             дизайн-система, компоненты, адаптив
  js/              api (с демо-режимом), анимации, корзина, страницы
backend/           PHP API (products, orders, auth, upload)
```
